# Userscripts (Tampermonkey / Violentmonkey)

Browser userscripts (`.user.js`) for decluttering feeds and improving web UIs.

- **`youtube_hider.user.js`**: Hides YouTube Shorts shelves, "Most relevant" shelves, and non-watch-page sidebars.
- **`facebook_marketplace_hider.user.js`**: Adds a persistent one-click `×` Hide button directly onto Facebook Marketplace browse tiles and listing photo galleries (persisted via `localStorage`).
